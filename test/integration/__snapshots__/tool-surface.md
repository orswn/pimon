## background

description: Run a long-running local command in the background. Actions: start, list, status, logs, stop. It reports nothing while running and wakes you once when the process exits; read output with action=logs. Use for tests, builds, and benchmarks. Pass timeoutMs=0 for a server that should run until stopped.
promptSnippet: Run long local commands detached with actions start/list/status/logs/stop

## timer

description: Wake this session later. action="set" arms a timer that starts or steers a run with its reason when it fires. Use it to come back to slow external work. During an active goal, also set one while waiting on a job, monitor, or bus reply. Timers end with the pi process.

## background_codemode

description: Run a codemode script as a background job. The script calls pi tools and MCP tools through tools.<name>(args), logs lines with emit(text), and waits with sleep(ms). No searchTools, describeTool, or models; store() does not persist. The tool returns at once; the exit wakes you with the result. Script tool calls run outside your turn, so do not let a script edit files you edit. Script jobs stop at /reload, session switch, and quit. Use background, not this tool, to stop it or read its log.
promptSnippet: Run a codemode script as a background job that wakes you on exit
promptGuidelines: []
schema: {"type":"object","required":["code"],"properties":{"code":{"type":"string","description":"Codemode script: an async function body, at most 100000 chars"},"name":{"type":"string","description":"Job name; letters, digits, dot, dash, underscore"},"timeoutMs":{"type":"number","description":"Abort the script after this long; 0 disables (default 1800000, max 86400000)"},"notifyExit":{"type":"boolean","description":"Wake on exit with a digest (default true)"}}}

Script tool calls run outside your turn, so do not let a script edit files you edit. Script jobs stop at /reload, session switch, and quit. Use monitor, not this tool, to stop it or read its log.
